## 一、项目简介

李文亚（河南邓州，1959 年生，自称"宇宙第一物理学家"）自 2024 年起在短视频平台发布大量讲解"星球三重引力范围""黑体生物""太阳直径 42 亿千米"等理论的视频，并长期与网友扮演的"孙笑川教授""114514 研究所"等虚构学术势力展开论战。这一系列内容在中文互联网形成了规模庞大、设定自洽的二次创作生态。

本仓库不做评论、不做科普、不做真伪判断，只做一件事：**把这些视频的语音识别（ASR）转写稿完整、结构化地保存下来。**

之所以值得做，是因为：

- **平台内容易失。** 账号封禁、视频下架、链接失效，原始材料随时可能永久消失（2026 年 6 月起其账号已被封禁）。
- **口语语料稀缺。** 豫西南方言口语、非专业科学话语体系、情绪化表达，是标准书面语料库中极少覆盖的语言样本。
- **可检索才有价值。** 1,239 篇散落视频无法检索；转成纯文本后，"孙笑川"（2,165 次）、"黑体生物"（868 次）、"枪毙"（264 次）等高频话语的分布与演变可以被量化统计。

一句话概括：**这是档案，不是立场。**

## 四、功能特性

### 1. 九大主题分类体系
按内容主题而非发布时间归档，T01–T09 覆盖从天体物理理论到网络论战事件的完整话语光谱。研究者可直接按主题切片取用。

### 2. 全局唯一编号 `LWY######`
每篇带编号的转写稿都有唯一 ID，跨分类不重复、可稳定引用。写论文、做标注、建索引时直接引用 `LWY000042` 即可，无需依赖易变的文件路径。

### 3. 一行一句的 ASR 断句格式
转写稿按语音识别的自然停顿切行，**一行一句**，天然适合：
- 逐句标注与情感分析
- 句长分布、语气词、重复修辞统计
- 直接作为 NLP 分句任务的输入（省掉分句步骤）

### 4. 纯文本，零依赖
UTF-8 纯文本、无 BOM、LF 换行。不需要数据库、不需要解析器、`cat` 和 `grep` 就能用。任何语言、任何平台的工具链都能直接读取。

### 5. 文件名即索引
标题被完整保留在文件名中（`T04_LWY000002_..._宣布推翻万有引力等定律...`），不打开文件内容就能完成一轮主题筛选，配合 `ripgrep` 可实现毫秒级全库检索。

### 6. 双格式并存
- `.txt` — 去时间轴的纯文本，适合语料统计与模型训练
- `.srt` — 保留毫秒级时间轴（含 `.ai-zh` 机翻校对版、`.fixed` 修正版变体），适合回溯原始视频位置、做字幕研究

### 7. 可追溯
文件名保留来源标题与处理标记（如 `.ai-zh`、`.fixed`、`_修复`），转写质量与处理链路一目了然，便于后续人工校对时定位低置信度文本。

### 5.3 用 Python 读取

```python
from pathlib import Path

CORPUS = Path("李文亚")

def load_corpus(limit=None):
    """加载全部转写稿，返回结构化文档列表。"""
    docs = []
    for i, path in enumerate(sorted(CORPUS.rglob("*.txt"))):
        if limit and i >= limit:
            break
        text = path.read_text(encoding="utf-8")
        stem = path.stem
        parts = stem.split("_")
        docs.append({
            "id":   parts[1] if len(parts) > 1 and parts[1].startswith("LWY") else None,
            "cat":  path.parent.name,
            "title": stem,
            "text":  text,
            "lines": text.splitlines(),   # 一行一句，可直接做逐句分析
        })
    return docs

docs = load_corpus()
print(f"共加载 {len(docs)} 篇，总字数 {sum(len(d['text']) for d in docs):,}")
```

### 5.4 从 SRT 提取纯文本

```python
import re
from pathlib import Path

def srt_to_txt(path) -> str:
    """剥离 SRT 的序号行与时间轴行，返回纯文本。"""
    raw = Path(path).read_text(encoding="utf-8").strip()
    lines = []
    for block in re.split(r"\n\s*\n", raw):
        seg = [l for l in block.splitlines() if l.strip()]
        lines.extend(seg[2:])          # 丢弃第 1 行序号、第 2 行时间轴
    return "\n".join(lines)

print(srt_to_txt("李文亚/T09_李文亚教授_人物事件网络平台与社会观点/【新民科TV】讣告！李文亚同志 逝世！.srt")[:120])
```

```

     │          │              │              │
     │          │              │              └─ 该视频转写内容的中文摘要

     │          └─ 全局唯一编号，000001–001231

示例：

```
T04_LWY000002_李文亚教授_宣布推翻万有引力等定律并提出星球引力理论.txt

**编号与分类保持一致**：文件所在目录的 `TXX` 与文件名前缀的 `TXX` 始终相同，便于校验归档错误。

## 八、数据格式说明

### `.txt` 转写稿

- **纯转写正文**，无标题行、无元数据头、无时间戳。
- **一行一句**，按 ASR 自然停顿切分；空行即段落边界。
- 保留口语原貌：重复、修正、口误、方言词、ASR 错字（如"量级"实为"两极"）**均未做修正**。

```
我叫李文亚
今天讲解地球自转
太阳东升西落
我这里有一个篮球
这个篮球和地球的对比分析
```

> ⚠️ **使用提醒**：ASR 转写存在可观的识别错误，专有名词与物理术语尤甚。做严谨的语言学或内容分析前，请务必对关键片段**回听原始视频校对**，不要直接把转写文本当作权威引文。

### `.srt` 字幕

标准 SubRip 格式，含毫秒级时间轴：

```
1
00:00:00,000 --> 00:00:03,200
我们的身体里面的这个黑体生物啊
```

变体后缀：`.ai-zh`（机器翻译/校对版）、`.fixed`（人工修正版）。

### 提交前请检查

```bash
# 1. 编码必须是 UTF-8 无 BOM
file -I 你的文件.txt          # 应输出 charset=utf-8

# 2. 换行符必须是 LF（不是 CRLF）
file 你的文件.txt             # 不应出现 "CRLF line terminators"

# 3. 编号不得与既有编号重复
ls 李文亚/*/ | grep -o 'LWY[0-9]\{6\}' | sort -u | wc -l

# 4. 文件名前缀 TXX 必须与所在目录一致
```

提交信息请简明说明来源与处理过程，例如：`新增 T09 转写稿 3 篇 / 已人工校对时间轴`。
